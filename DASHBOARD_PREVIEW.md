## Card Breakdown

### 1. Picture Entity Card (Top)
- **Aspect Ratio**: 16:9
- **Content**: 
  - Your Tesla car image
  - Car name (from TeslaMate)
  - Current location/geofence
- **Interactive**: Tap to see device details

### 2. Status Row (3 cards)
- **Status Card**: Current car state (online/asleep/charging)
- **Battery Card**: Current battery percentage with icon
- **Range Card**: Estimated range in km

### 3. Battery & Charging Card
Displays comprehensive charging information:
- Current battery level with percentage
- Usable battery level
- Charge limit setting
- All range estimates (estimated, rated, ideal)
- Plugged in status
- Current charging state
- Charger power in kW
- Time remaining to full charge

### 4. Climate Card
Temperature and climate control status:
- Climate on/off status
- Inside cabin temperature
- Outside ambient temperature
- Preconditioning status

### 5. Security & Status Card
Complete security overview:
- Lock status with icon
- Sentry mode status
- All windows status
- All doors status
- Trunk and frunk status
- User presence detection

### 6. Map Card
Interactive map showing:
- Current vehicle location
- Historical path (last 24 hours)
- Zoom and pan controls
- Tap to open full map view

### 7. Location Details Card
Detailed location information:
- Current GPS location
- Geofence name (if in one)
- Current speed
- Heading direction
- Shift state (P/R/N/D)

### 8. Vehicle Information Card
Static vehicle details:
- Tesla model
- Trim badging
- Exterior color
- Current software version
- Available update version
- Total odometer reading

### 9. Tire Pressure Gauges
Visual gauges for all four tires:
- Front left and right
- Rear left and right
- Color-coded:
  - Green: Good pressure (>2.5 BAR)
  - Yellow: Low warning (2.2-2.5 BAR)
  - Red: Critical (<2.2 BAR)

## Real-time Updates

All cards update in real-time as MQTT messages arrive:
- ⚡ Battery level updates while charging
- 📍 Location updates while driving
- 🌡️ Temperature updates continuously
- 🔒 Status changes instantly

## Mobile View

The dashboard is fully responsive:
- Cards stack vertically on mobile
- All information remains accessible
- Tap cards for more details
- Swipe map to navigate

## Customization Options

You can easily customize:
- **Colors**: Match your car color
- **Layout**: Rearrange card order
- **Cards**: Add/remove cards
- **Themes**: Apply HA themes
- **Picture**: Use any car image
- **Units**: Change km to miles, °C to °F

## Color Themes

The dashboard works with all Home Assistant themes:
- Light mode
- Dark mode
- Custom themes
- Auto-switching themes

## Interactive Elements

### Clickable Cards
- Tap any card to see more details
- Tap map to open full screen
- Tap picture to see device info

### Navigation
- Swipe between dashboard views
- Quick access from sidebar
- Mobile app integration

## Notifications Integration

When combined with automations, you get:
- 📱 Push notifications
- 🔔 Action buttons
- 📊 Status updates
- ⚠️ Alerts and warnings

## Additional Views (Optional)

You can add more views for:
- **Charging History**: Track past charging sessions
- **Trip Statistics**: Miles driven, efficiency
- **Cost Tracking**: Electricity costs
- **Maintenance**: Service reminders
- **Comparison**: Multiple cars side-by-side
